## ✨ Особенности

- ✅ **Создание и управление задачами** с категориями и приоритетами
- 👤 **Аутентификация пользователей** с защитой сессий
- 🎨 **Современный темный дизайн** с поддержкой темной/светлой темы
- 📱 **Адаптивный интерфейс** для всех устройств
- 🔔 **Уведомления о дедлайнах** и напоминания
- 📊 **Статистика продуктивности** и отчеты
- 🔍 **Поиск и фильтрация** задач по различным параметрам
- 🏷️ **Теги и метки** для организации задач

## 🛠 Технологии

**Backend:**
- Python 3.11+ - основной язык программирования
- Flask 3.0 - легковесный веб-фреймворк
- Flask-Login - управление аутентификацией
- Flask-SQLAlchemy - ORM для работы с БД
- Flask-WTF - формы и валидация

**Frontend:**
- HTML5, CSS3, JavaScript (ES6+)
- Bootstrap 5.3 - адаптивная CSS-библиотека
- Dark/Light theme switcher
- Responsive design principles

**База данных:**
- SQLite (разработка и демо)
- PostgreSQL (продакшен версия)
- Миграции через Flask-Migrate

**Деплоймент:**
- Railway - облачная платформа
- Docker контейнеризация
- CI/CD пайплайны
